# 检测场景

12个苹果样本分4批，每个样本初检P01为<0.01mg/kg，采样日标准限量0.005，因此不确定。次日同样本同方法复检0.004且LOD0.001，判为PASS并替代原报告。每样本P02为30ug/kg，超过0.02mg/kg，仍FAIL。最终24项目，12PASS、12FAIL，四批均FAIL。脏批额外含缺LOD、同版冲突、错列、空行与重复表头。

## 合样分地块（composite.csv / composite_broken.csv）

两个总样C001、C002各由B1–B4四个地块合样，报告与合样单同时到达。P01总样初检0.009mg/kg，对0.005限量判FAIL；B2地块复检0.004判PASS，只缩窄B2，B1/B3/B4维持FAIL。P02总样为<0.01，对0.02限量PASS，未复检，仍覆盖四个地块。每总样8条地块结论，两批均因B1/B3/B4为FAIL而判FAIL。

合样单由样本参数 `composition_csv` 提供；直接选 `composite.csv` 时自动带入。

`composite_broken.csv` 的复检声明了合样单未登记的B9地块，本次裁决不可发布：四分地块全部标记BLOCKED，旧版已发布结果保留，运行仅作证据，归档导出返回409。
